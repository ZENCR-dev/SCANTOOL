# 开发约束（MVP）

写 Spec、拆任务、实现时必须遵守。与 [CONTEXT.md](../CONTEXT.md) 冲突时，以领域词为准；与本文件冲突时，先改约束或走 ADR，禁止静默破例。

## 交付标准

1. **MVP 必须端到端可用**：在目标 iPhone Safari 上能挂载收货表、连续扫一维码、写回已收/扫码时间，并在电脑收货表看到未收/已收。
2. **允许粗糙**：UI/UX、文案、动效、声音可简陋；不追求美观。不可用（扫不了、写不回、对不上账）不算交付。
3. **验收以手工 E2E 清单为准**（见 Spec）；自动化只覆盖两块纯逻辑缝。

## 产品边界

1. **要防**：漏收（未收清单可查）、重复扫（已收过须可区分反馈）。
2. **不主防错收**：不在清单 → 轻提示，不记已收，可继续扫。
3. **匹配**：仅 trim 后完全一致才算命中；不做包含/模糊/承运商专用解析。
4. **码制**：MVP 只保证一维条码；不承诺二维码。
5. **批次**：约 3～4 批临时使用；不做「复制模板 + 自动部署」产品功能。

## 架构

1. **唯一台账**：收货表（Google Sheet）。禁止另建业务数据库作为真相源。
2. **后端**：Apps Script Web App 提供挂载/扫码写回/统计 API（见 [ADR-0001](./adr/0001-apps-script-spa-sheet-ledger.md)）。
3. **摄像头宿主（已冻结）**：扫码 UI **不得**依赖 HtmlService iframe 内的 `getUserMedia`（沙箱会拦截）。须按 [ADR-0002](./adr/0002-camera-outside-apps-script-iframe.md)：HTTPS 静态扫码页 + 调用 Apps Script API。
4. **挂载**：扫码页粘贴表格链接/ID；读写该文件**第一个工作表**。
5. **同账号**：收货表须在部署所用 Workspace 账号下（或对其可编辑）。
6. **写路径**：每次新确认已收须立刻写表；不做离线队列/后台同步。写失败则本次不成立为已收，须明确报错。
7. **权限**：静态扫码页与 API「有链接即可用」；不强制 Google 登录（用完停用 Web App / 可撤静态页）。

## 收货表约定

1. 操作者事先将应收单号粘贴到 **A 列**（可手工从 Excel 复制）。
2. 表头为：`单号 | 状态 | 扫码时间`；挂载时若缺列可自动补齐。
3. **状态字面量（已冻结）**：
   - **已收** = 单元格值为 `已收`
   - **未收** = 单元格为空，**或**值为 `未收`（两者等价）
   - 写入新已收时只写 `已收`（加扫码时间）；不要把未收统一改写成 `未收`，除非用户显式要求
4. **挂载校验（已冻结）**：
   - 状态列若出现空/`未收`/`已收` 以外的值，**整表拒绝挂载**，并列出坏行（至少行号 + 单号 + 原值）
   - A 列应收单号（trim 后非空）若有重复，**整表拒绝挂载**，并列出重复的单号及行号
   - A 列 trim 后为空的行**跳过**，不计入应收，不报错
   - 必须改表后重新挂载才能开扫（仅针对校验失败的情形）
5. **扫码时间（已冻结）**：写入 Google 表格**原生日期时间**单元格（非纯文本）；时区遵循脚本/表格时区。已收过不改时间。
6. 已收过：提示且**不改**状态与时间。

## 扫码 UX 约束

1. 连续自动扫描；成功类结果后须有短冷却，避免同一面单连刷（秒数可默认，如 1.5s）。
2. 主界面以可区分的大反馈（新已收 / 已收过 / 不在清单）+「已收数 / 总数」为主；未收列表仅为小入口。
3. 「新已收」与「已收过」必须可区分（可用不同颜色块和/或不同提示音；允许极简实现）。
4. **粗糙允许**：布局挤、无品牌、无动画、文案生硬均可；功能路径必须通。

## 明确不做（MVP）

- 自建后端数据库、离线优先同步
- CSV/Excel 上传导入器（粘贴进 Sheet 即可）
- 模糊匹配、多 Tab 选择器、批次目录表
- 多用户协作权限模型、审计流水（超出 Sheet 历史之外）
- 精致 UI/动效/无障碍打磨（超出「可区分反馈」以外）
- 在 HtmlService iframe 内强行开摄像头当作主路径

## 写 Spec 时的要求

- 用户故事与验收用语必须使用 [CONTEXT.md](../CONTEXT.md) 中的词。
- Implementation Decisions 须点名遵守本约束与 ADR-0001/0002；若要破例，先新增/修订 ADR。
- 测试优先验证**外部行为**：扫码结果纯函数、挂载校验纯函数。不自动化测真实 Sheet/摄像头。
- 实现仍须保证写表失败时本次不成立为已收（E2E 手工验收）。
