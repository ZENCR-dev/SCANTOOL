# 03 — 真表 API：挂载并写成已收

**What to build:** 部署后的 Apps Script Web App 能对真实收货表完成挂载、把一次扫码写成已收（含扫码时间）、返回统计；全部可在**无摄像头**的情况下验证（脚本/临时页/手工调用即可）。写失败时明确报错且不出现假已收。

**Blocked by:** 01 — 扫码结果判定可单测; 02 — 挂载校验可单测

**Status:** ready-for-agent

- [ ] 粘贴表格链接/ID 可挂载第一个工作表；缺表头时可补齐 `单号|状态|扫码时间`
- [ ] 挂载走与票 02 相同的校验规则；失败时返回可展示错误
- [ ] 调用「扫码」接口：未收命中 → 表中为 `已收` + 原生日期时间；返回新已收
- [ ] 再次同一单号 → 已收过，表不变
- [ ] 不在清单 → 不写表；统计已收/总数正确
- [ ] 写表失败路径有明确错误，且调用方不得把该次当作已收成功
- [ ] API「有链接即可用」、以部署者身份访问其可编辑的收货表（符合 ADR-0001）
